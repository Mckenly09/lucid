# Pokus ng Pandiwa

Ang **pokus** ng pandiwa ay ang relasyon ng pandiwa sa **paksa** (simuno) ng pangungusap. Ang panlapi ng pandiwa ang nagsasabi kung ano ang papel ng paksa. Karaniwang makikilala ang paksa sa pananda nitong *ang*, *si* o *sina*.

## Mga uri ng pokus

1. **Pokus sa tagaganap o aktor** (actor focus): ang paksa ang gumagawa ng kilos. Panlapi: *-um-, mag-, ma-, mang-, maki-*. *Si Ana ay **nagluto** ng adobo.* Tanong: Sino ang gumawa?
2. **Pokus sa layon** (object focus): ang paksa ang tumatanggap o pinag-uukulan ng kilos. Panlapi: *-in, -hin, i-, ipa-, ma-*. ***Niluto** ni Ana ang adobo.* Tanong: Ano ang ginawa?
3. **Pokus sa ganapan** (locative focus): ang paksa ang lugar na pinangyarihan ng kilos. Panlapi: *-an, -han, pag-...-an, pinag-...-an*. ***Pinaglutuan** ni Ana ang malaking kaldero.* Tanong: Saan ginawa?
4. **Pokus sa tagatanggap** (benefactive focus): ang paksa ang nakikinabang sa kilos. Panlapi: *i-, ipag-, ipinag-*. ***Ipinagluto** ni Ana ang kaniyang ina.* Tanong: Para kanino?
5. **Pokus sa gamit** (instrumental focus): ang paksa ang kasangkapang ginamit. Panlapi: *ipang-, ipinang-*. ***Ipinanluto** ni Ana ang bagong kawali.* Tanong: Sa pamamagitan ng ano?
6. **Pokus sa sanhi** (causative focus): ang paksa ang dahilan ng kilos. Panlapi: *i-, ika-, ikina-*. ***Ikinatuwa** ng pamilya ang masarap na adobo.* Tanong: Bakit?
7. **Pokus sa direksiyon** (directional focus): ang paksa ang tinutungo ng kilos. Panlapi: *-an, -han, -in, -hin*. ***Pinuntahan** ni Ana ang palengke.* Tanong: Tungo saan?

## Paano matukoy ang pokus

- Hanapin ang paksa: ang pariralang may *ang*, *si* o *sina*.
- Itanong kung ano ang ginagampanan ng paksa: gumawa, ginawan, lugar, nakinabang, ginamit, dahilan o tinungo.
- Tingnan ang panlapi ng pandiwa bilang dagdag na palatandaan.

## Gamit sa pagsulat

Ang pagbabago ng pokus ay nagbabago ng **diin** ng pangungusap. Kung nais idiin ang gumawa, gamitin ang pokus sa aktor. Kung nais idiin ang bagay na ginawa, gamitin ang pokus sa layon.
